# Phase 5–6 验证记录

## 本次接入

- 原版共享 UI 已接入 Forge 1.7.10。涵盖推荐、排行榜、搜索、歌单、列表和封面墙、歌手、专辑、队列、扫码与设置。保留原版字体、布局、动画和玻璃着色器。
- 已接入 HUD 和世界渲染事件、Song Card、灵动岛、逐字及 3D 歌词、发光和文闪代码。光影、世界遮挡与 HUD 交互仍需分别验收。
- 使用 GTNH 实例内 Angelica 的实际 GL 路径。基础播放窗口用作着色器初始化失败时的备用入口。
- 一起听歌及 Firebase 页面已移除。上游自动更新提醒也已拆除，避免向 GTNH 用户提示安装面向其他 Minecraft 版本的 JAR。
