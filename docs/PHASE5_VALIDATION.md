# Phase 5–6 验证记录

## 本次接入

- 原版共享 UI 已接入 Forge 1.7.10。涵盖推荐、排行榜、搜索、歌单、列表和封面墙、歌手、专辑、队列、扫码与设置。保留原版字体、布局、动画和玻璃着色器。
- 已接入 HUD 和世界渲染事件、Song Card、灵动岛、逐字及 3D 歌词、发光和文闪代码。光影、世界遮挡与 HUD 交互仍需分别验收。
- 使用 GTNH 实例内 Angelica 的实际 GL 路径。基础播放窗口用作着色器初始化失败时的备用入口。
- 一起听歌及 Firebase 页面已移除。上游自动更新提醒也已拆除，避免向 GTNH 用户提示安装面向其他 Minecraft 版本的 JAR。

## 简体中文与输入法

- `dev.5.2` 首次启动默认简体中文。读取已保存的语言选择，避免覆盖用户手动设置。隔离实例将早期开发版保存的英语自动值重置后复测。
- 检查了本机 lwjgl3ify 3.0.42 的 InputEvents 和 SDL 事件循环。搜索或筛选等输入框获得焦点时调用 beginTextInput，失焦或关界面时调用 endTextInput。提交后的 SDL 文本沿已有 LWJGL 字符事件交给搜索框，避免重复插入。
- 在 GTNH 2.9.0 / Java 25.0.3 / Angelica 的 780 × 500 隔离实例中，测试模组走实际主菜单按钮点击。开启搜索焦点后，输入适配器将 SDL 文本输入深度增加 1。测试向 lwjgl3ify 的提交字符队列注入“周杰伦 晴天”，搜索框收到完全一致的文本，画面显示中文标题及输入。失焦后输入深度回到原值。Windows 拼音候选与系统剪贴板未进行实机交互验证。
