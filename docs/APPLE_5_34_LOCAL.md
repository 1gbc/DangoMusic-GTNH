# 5.34-local：基于 5.33 的本地测试版

本文件记录最初的本地测试阶段；后续已获授权提交源码，尚未发布发行包。JAR 与 apple-player 需要同时更新，保留整个 accounts 目录。

本地组件随包带 .NET 运行库，不需要另装 .NET 8 Desktop Runtime；仍需要 WebView2 Runtime。包含此前 UI PR 的连续曲率圆角和播放按钮组居中。

- 播放组件启动后在后台工作，不显示 Apple Music 网页主界面，不需要 Chrome、扩展或复制配对链接。
- 在游戏按 M，选择 Apple Music；搜索、热门歌曲、媒体库、歌单、队列、播放/暂停、上下首、进度和音量仍用 DangoMusic 原有界面。
- 首次登录或会话失效时，通过游戏账号入口点击“Apple 官方账号授权”。只允许 Apple 官方授权弹窗显示；不在 Mod 内仿制密码表单。授权完成后自动关闭弹窗。若授权无法弹出，须如实反馈，不把打开网页当作替代验收。
- 歌词页面、HUD 与 3D 歌词复用原有 Lyrics 模型和播放时钟。进入世界，在设置里打开 Lyrics/3D lyrics。暂停、跳转、切歌跟随同一播放状态。
- 本地歌词优先；其次按完整歌名、歌手和时长差不超过 2 秒匹配网易云歌词。候选同分或疑似不同版本时不套用。来源为匹配歌词，不声称是 Apple 官方歌词。匹配失败最多每十分钟重试，避免频繁网络开销。

## 导入歌词

放入 `.minecraft/config/dangomusicgtnh/lyrics/apple/`，文件名为 `apple-歌曲AppleID.lrc`，也支持 `.yrc`、`.ttml`（优先级 TTML、YRC、LRC）。支持普通数字目录 ID 和库 ID；含路径符号的 ID 使用歌曲 key 的 SHA-256 文件名。导入/替换后重启游戏以刷新已有歌词缓存。

TTML 支持绝对秒/ms、时分秒时间戳，以及带 begin/end 或 dur 的逐字 span；不支持帧制/相对容器计时，不把无逐字时间的歌词伪装成准确逐字歌词。本地 TTML 按主要文本解析，复杂翻译/音译布局未完整适配。

可在同目录添加 `apple-歌曲AppleID.offset`，内容是整数毫秒；正数使歌词更晚显示，例如 `500`。范围 ±600000 毫秒。

## 验收与限制

编译、模拟通信、歌词解析通过不等于真实会员完整播放通过。仍需用户验证授权、超过试听时长的实际出声、隐藏组件后播放、游戏内操作和世界里的 3D 歌词同步。后台组件仍使用 WebView2 播放内核，保留 5.33 的独立本机账号资料。

建议先搜索并播放一首熟悉的歌，拖到 120 秒确认仍出声，然后进入世界观察歌词。找不到匹配歌词时用自己的 LRC/TTML 测试；不要把“无歌词”判作播放失败，也不要把进度变化判作成功出声。
