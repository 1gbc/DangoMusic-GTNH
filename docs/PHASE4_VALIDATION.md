## 2026-11-05 网易云播放回归

- 实机日志中多首曲目的播放 API 外层返回 200，曲目条目返回 404 且没有音源地址。另有曲目取得 MP3 地址，但线程长时间等待 CDN 响应体，随后部分请求抛出 SSLException。两种失败分别发生于音源解析与下载阶段。
- 当前网络的匿名复测中，曲目 2624235389 返回 MP3。CDN 返回 HTTP 200、约 3.34 MB；前约 10.4 秒收到约 1.22 MB。Range 请求返回 HTTP 206，并在约 4 秒内完成 256 KiB。
- `dev.5.3` 对网易云下载增加可见进度、整体时间限制、响应诊断和过期请求取消。下载在收到部分音源后遇到 I/O 错误时，尝试一次 Range 续传，核对返回范围再拼接。Gradle 构建通过，本机 HTTP 测试验证了 404 分类、进度、取消和断点续传。重混淆 JAR 在独立 JVM 用同一曲目 2624235389 复测，完成下载、解码、暂停和继续。游戏内新版待复测。
