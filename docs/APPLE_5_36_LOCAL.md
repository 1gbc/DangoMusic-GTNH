# 5.36-local：播放修复与真实验证

基于 5.33，保留 5.34/5.35 本地版的原生游戏界面、首页分区、连续圆角、居中控件及歌词/3D 歌词接入。本文件记录本机构建和安装的验证结果；后续已获授权提交源码。

## 本次修复

- 官网自身登录入口完成账号会话初始化，避免只调用 SDK 授权而没有建立官网播放会话。首次必要时显示官方授权页面，完成后回到后台；日常搜索、歌单、队列和播放仍在 DangoMusic 游戏界面操作。
- 使用公开的账号 storefront API 和 MusicKit storefrontId 设置接口对齐地区，解决实测 CONTENT_EQUIVALENT 入队失败。保留正常地区、授权和订阅校验，不修改 SDK 私有成员。
- 媒体加载异步进行，心跳继续运行，避免原先 7 秒等待阻塞控制和同步。最多等待 60 秒，并保留 SDK 错误类别。停止或换歌可取消旧请求，旧任务不得恢复播放。
- 不显示网页音乐主界面的前提下保持 WebView2 媒体宿主运行，避免隐藏控件后的初始化挂起。
- 使用 SDK FULL_PLAYBACK_ONLY 模式，不能把试听回退当作完整播放成功。播放授权仍由 Apple 服务端校验。
- 列表仅跟随服务端给出的分页游标，不再根据一批数据的数量猜下一页，避免末页额外请求导致的 HTTP 404。
- 组件正常退出后再回收进程，给本机账号资料正常保存的机会。accounts 与个人设置不覆盖。

## 验证证据与边界

- 真实账号：仅完整播放模式下进度推进到 4 秒；跳到 90 秒后继续到 94 秒，组件随后记录约 95 秒。用户确认原段和跳转后都有声音。
- 同一账号配置正常退出后再次启动，返回 connected=true、authorized=true、authState=ready；本次没有重新登录。
- 编译和发布通过；10 项 Node 回归、Java 通信/队列、歌词模型和解析、无控制台 UTF-8 启动检查通过。
- 这些真实播放测试使用与游戏相同的组件和本机通信服务，不是模拟播放器；但没有在游戏世界内目视验证 3D 歌词。本次也没有测试全部歌曲、地区、音质、长期后台运行或所有异常恢复。

## 使用

直接启动 你的测试实例，按 M 选择 Apple Music。已有有效登录应恢复；如出现官方登录窗口，在该窗口完成即可。主页可刷新最近播放、推荐、媒体库和歌单。

歌词优先本地 LRC/YRC/TTML，其次保守匹配网易云同歌名、歌手和近似时长的版本。需要在世界内启用 Lyrics / 3D lyrics；无可用时间轴的歌曲不能凭空显示歌词。

若再次失败，保留 `config/dangomusicgtnh/apple-player/diagnostics.json`，其中只有固定错误代码和播放/授权状态，不含账号、Cookie、令牌、响应正文或音频。
