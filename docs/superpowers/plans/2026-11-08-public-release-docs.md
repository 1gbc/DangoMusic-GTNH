# 公开发布准备计划

本计划落实维护者已给定的许可证审查、来源说明、中文主页与 PR 交付要求。只修改文档、署名元数据和打包许可材料，不新增播放功能，不改变仓库可见性，不发布 Release。

## 文件与职责

- README：玩家入口、实际功能状态、环境与下载指引。
- `docs/INSTALL.md`：当前安装步骤、Apple 组件和配置缓存说明。
- `docs/RELEASE_AUDIT.md`：固定源码基线、许可证依据、扫描范围及未解决项。
- `THIRD_PARTY_NOTICES.md` / `CREDITS.md`：第三方组件及上游和贡献者来源。
- `docs/RELEASE_DRAFT.md` / `docs/REPOSITORY_METADATA.md`：供审核的发布正文和 About/Topics。
- `src/main/resources/META-INF/`：随下一次构建进入 JAR 的许可副本；`mcmod.info` 校正移植项目链接与署名。
- 现有 Apple 文档保留历史正文，顶部指向当前指南；更新 CHANGELOG 的未发布区。
