# 5.35-local：原生首页与播放排查

基于 5.33，保留 5.34 的原生界面、后台组件、连续圆角和歌词/3D 歌词接入。本文件记录最初的本地构建阶段；后续已获授权提交源码。

- Apple 首页补最近播放、为你推荐、常用入口分区。卡片内容来自账号公开 API 返回的专辑、歌单和电台，沿用游戏内封面网格；不承诺和官网首页每一项完全相同。
- 专辑/歌单卡片打开对应曲目，电台通过官方播放器的 station 队列描述播放。登录完成后刷新原生媒体库与首页。
- 游戏选歌会取消未完成的后台列表请求；此类主动取消不再被统一显示成“登录、地区和网络错误”。真正的通信超时、HTTP 拒绝和播放异常分别显示错误代码。
- 组件允许由游戏按钮触发媒体播放，不要求在隐藏网页中再点一次播放。此项处理浏览器用户手势限制，不能代替真实授权、订阅或 DRM 验证。
- 组件在 `config/dangomusicgtnh/apple-player/diagnostics.json` 保存最近一次操作的有限诊断：操作类型、固定错误代码、授权/播放布尔状态和进度。不记录歌名、账号、Cookie、令牌、请求 URL 或响应正文。

验证：进游戏后在首页点刷新；打开最近播放或推荐卡片选歌；确认实际出声和跳转后继续出声。若仍失败，提供界面里的错误代码或 diagnostics.json，不能仅凭模拟检查认定真实播放已修复。WebView2 与 Apple 网站兼容性仍需实测。

原有账号资料、个人设置和 accounts 目录保留；无需退出 Apple 账号重新安装。旧 JAR 和播放组件备份在实例外层 codex-mod-backups。
