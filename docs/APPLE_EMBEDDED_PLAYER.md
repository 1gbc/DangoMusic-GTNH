# 无外部浏览器的 Apple Music 接入验证

## 用户要求

登录后尽量在游戏内操作，不需保持外部浏览器；实际播放方式参考网易云。继续使用已有音源、配置和一起听，目标 GTNH 2.9.0 / Forge 1.7.10。

## 本次技术选择

现有网易云后端下载并解码音频，不适用于直接承载 Apple DRM 音轨。选择 Mod 管理的 Windows WebView2 附属播放组件，保留官方网页与权益校验；不提取 Apple 音频 URL、不将受保护音频转入 Java Sound。组件独立于 Chrome 配置，游戏通过已有本机协议管理播放器。Windows 已安装 Evergreen Runtime 156.0.4314.58，但真实 Apple 完整播放仍需验证。

## 实现与检查

- [x] 同一一次性凭据允许 `dango-native://player` 配对，仍绑定会话来源；原扩展来源不变。
- [x] 配对参数经父子进程 stdin 管道发送，避免出现在进程参数、日志和磁盘。
- [x] Mod 提供启动/显示/隐藏组件入口，持有自己创建的进程句柄。
- [x] 独立本机账号资料；只允许 Apple HTTPS 页面导航与登录弹窗。
- [x] 检查父进程与会话心跳，退出时回收自己创建的组件。
- [x] 依赖包微软作者与 NuGet 仓库签名验证、.NET 编译、无界面启动自检、Java 原生协议测试。
- [ ] 用户实测内嵌登录、完整播放、后段跳转、隐藏后连续播放、退出清理。
- [ ] 通过后将搜索/媒体库/队列接入游戏内操作；后续歌词及多人同步分别验证。

## 验收边界

这是一条新的受保护播放环境。Chrome 中已验证的行为不能算作 WebView2 已验证。先交付 5.30 实验 JAR 和组件，让用户验证真实播放。若原生宿主无法完整播放，记录具体结果并保留 5.29 回退路径，不能宣称纯游戏内播放已完成。
