# 5.37-local：歌词锚点、最近播放与方形按钮

保留 5.36 通过真实出声和 90 秒后继续播放验证的后台播放流程，保留本地测试版本号；源码现已获授权提交 GitHub，尚未发布发行包。

- 歌词：移除“播放进度变化超过 300 毫秒就重新生成世界位置”的逻辑。Apple 的遥测约每 700 毫秒到达，这不等于用户跳转；现在由实际歌词行索引决定换行，同一句不会因进度同步而重新随机位置。真实跨句跳转仍由行索引处理。
- 最近播放：按 Apple 接口要求传递 types，并把 limit 从 25 改为上限 10，修复 HTTP 400 / code 40005 请求。单个首页分区失败时显示中文提示，推荐和其他入口继续保留。
- 控件：队列、停止及其他小播放控件统一 32×32；模式菜单选中块改为 26×26，图标随按钮几何中心对齐。播放圆盘保留圆形，整组控件按新的总宽度居中。

构建、接口参数回归和已有歌词检查不等于已经在游戏世界目视验证。请重点观察同一句歌词是否固定、最近播放是否恢复、弹出模式菜单和停止键是否保持方形。

补充验证：真实账号的最近播放接口返回 10 项，错误为空。对实际 LyricsModule.updateClock 的无 GPU 回归检查中，700 毫秒遥测和句内跳转不再重置当前行；同一检查在旧 5.36 上失败，在 5.37 上通过。

JAR 与 apple-player 同步更新，原账号资料和个人设置保留。
